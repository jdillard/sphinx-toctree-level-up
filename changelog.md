# Changelog

## 0.1.1 - 2026-08-26

- Add CI coverage for Python 3.10–3.13 and Sphinx 7–9.
- Add Regression tests for the singlehtml, Texinfo, and man builders.
- Preserve `only` conditions when promoting content in single-file builders.

## 0.1.0 - 2026-08-26

- Initial release with `toctree` `:level-up:` and the `toc-level-up` directive.
- HTML and single-file builder support.
- Automatic deactivation when Sphinx provides native `:level-up:` support.
